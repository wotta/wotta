### Hi, I'm Wouter 👋

Self-taught developer. I spent 5½ years in an egg processing plant, teaching myself to code after becoming a dad at 19. Since 2016 I've worked in software, mostly back-end with Laravel (since 4.2).

These days I'm an interim Product Owner (PSPO I) at [Kaartje2go](https://www.kaartje2go.nl). I'm an engineer by trade and a product owner by curiosity. I still build side projects in the evenings.

- 🛠️ **Stack:** Laravel, Inertia, React, TypeScript, Filament
- 🧪 **Things I care about:** test suites, error monitoring, shipping small and often
- 🤖 **Currently exploring:** AI tooling and agent workflows for developers
- 🤝 **Community:** active in [Torc.dev](https://platform.torc.dev/#/r/BXYMEtjw/cp), helping people get into tech
